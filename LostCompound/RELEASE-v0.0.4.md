# LostCompound v0.0.4

**2026-11-22** · 上一版 v0.0.3-alpha（2026-10-31）· 84 个提交

---

一款单文件、免安装的 C# 控制台 roguelike。

这一版把**放射性区域**从设计文档变成了能玩的一张图，
再补了两个新 Boss 和五只新怪，最后把战斗日志的节奏和信息量重做了一遍。

---

## 这版有什么

**放射性区域**
第 10 层固定这张图。每格的辐射间隔由柏林噪声铺出来，拉伸到 5~15 秒 ——
数字越小越致命。时间是**真秒**：挂机、看菜单都在掉血，换房间清零。

**热力图**
拿到盖革计数器后自动弹出一个独立窗口，7 档颜色把整张图的辐射强度画出来。
越红越危险，`*` 是你，`·` 是空房间。

**两个新 Boss**
沙漠的**沙葬者**（吸你的沙回血，沙必须在战斗中当场变成战斗力）和水淹洞穴的**涨潮者**
（每两回合涨水回血，堵住出水口才能断它粮）。

**五只新怪**
放射性区域的**秒针虫**（不打你，但让辐射快一倍）与**放射僵尸**（越拖打越疼）；
6-12 层的**装甲**（拆甲反噬）、**寄生虫**（污染背包）、**活棱镜**（伤害反弹）。

**战斗日志重做**
清屏从「回合开头」挪到「动作真正生效那一刻」。
怪物打完你之后不会再被立刻擦掉；高温这类整场不变的机制写进日志框标题。

**敌人框更像杀戮尖塔了**
名字后面直接显示本回合意图（`打 N` / `盾 N` / `加速×2`），
有护盾时还会写 `盾 5.0` —— 龙和沙葬者的盾以前是隐形的。

**行为计数**
一回合能行动的次数现在是数据，默认 1；设成 2 就是城市双动，
还能和「额外回合」叠加（2 + 1 = 一回合动 3 次）。

**后台重绘**
不用按任何键，血量和信息框会自己刷新 —— 这是辐射能走秒的前提。

**还有**
背包丢弃、饰品栏返回清屏、查背包/查配方不再消耗回合、
非环境辐射改成「同类按数量叠伤害」、战斗时间轴窗口、131 传送。

## 怎么玩

下载 `LostCompound.exe`，双击。不需要装 .NET。

```
主菜单：  有存档 1 继续 / 2 新游戏 / 3 退出
          无存档 1 开始 / 2 退出
地图：    0 上  1 下  2 左  3 右  4 退出（会存档）  5 用道具  6 合成  7 饰品栏
战斗：    1 攻击  2 防御  3 背包  4 徒手合成  5 饰品栏（沙漠多 6 采沙）
```

重置全部进度：删掉 `%APPDATA%\LostCompound\` 下的 `profile.json` 和 `save.json`。

热力图想单独再看一次：

```
powershell -NoProfile -ExecutionPolicy Bypass -File radmap.ps1
```
