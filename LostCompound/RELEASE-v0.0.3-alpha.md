# LostCompound v0.0.3-alpha

**发布日期**：2026-10-31
**上一个版本**：v0.0.1-alpha（2026-10-15）
**这版范围**：58 个提交

---

## 一句话

从「一层迷宫 + 战斗」变成了「**10 层地下城 + 存档 + 档案 + 通关解锁**」，
并新增了水淹洞穴的两只专属怪、第三张地图（沙漠）和一件玩笑道具（镜子）。

---

## 亮点

### 10 层地下城
- 共 10 层，每两层地图长大一圈：5×5 → 6×6 → 7×7 → 8×8 → 9×9
- 每层种子 = 本局总种子 × 层数（同一总种子同一层永远同一张图）
- 打完 Boss 进下一层：**回复 70% 上限的血**，立刻自动存档
- 第 10 层 Boss = 通关

### 存档与「继续游戏」
- `%APPDATA%\LostCompound\save.json`（约 1 KB，只存种子与进度坐标）
- 点窗口 × / Ctrl+C / 注销 / 关机都会自动存档
- **任何时刻按 × 都能存**：不在安全点时存「最近的安全点」

### 档案（和存档分开）
- `%APPDATA%\LostCompound\profile.json`
- 第一次启动问名字，往后跨对局保留
- 三个彩蛋名字：

| 输入 | 结果 |
|---|---|
| `Hyberty` | 该名称已经被注册!（让你重输） |
| `buffmort` | 称号「开发者?」 |
| `aliamgad` | 称号「老朋友.」 |

### 通关解锁（第十章）
| 累计通关 | 解锁 |
|---|---|
| 2 次 | 背包 15→18，送 2 玻璃罐，开局道具选择 3→4 轮 |
| 4 次 | 背包 18→22，送 1 玻璃罐，选择轮数 4→5 |
| 5 次 | **解锁配方 1**（9 条合成） |
| 9 / 10 次 | 初始 DEF +10 / 初始生命 +20 |
| 1/3/5/7 次 | 各多一层「可自选下一层地图」 |

## 新地图：沙漠
- 只能拿到沙子（宝箱 / 空房 / 开局池都只给沙子）
- 怪物不掉落任何东西
- 战斗菜单多一项「**6. 采沙**」：1 回合换 5 沙子

## 新道具
- **硫酸剑**（配方 0）：铁剑 + 硫酸 → 合成出来立刻消失
- **镜子**（配方 0）：5 压缩沙瓶 + 白磷 + 玻璃罐 + 2 金属
  对换 Base 属性 + 轮换背包数量，连用会换「左旋 / 右旋」，
  名字也会变成「左旋-你的名字」

## 怎么玩

下载 `LostCompound.exe` 双击即可（**不需要装 .NET**）。

```
第一次启动：起名字 → 选环境 → 开始游戏

主菜单：  有存档 1 继续 / 2 新游戏 / 3 退出
          无存档 1 开始 / 2 退出
地图：    0 上  1 下  2 左  3 右  4 退出（会存档）  5 用道具  6 合成  7 饰品栏
战斗：    1 攻击  2 防御  3 背包  4 徒手合成  5 饰品栏（沙漠多 6 采沙）
```

想重置全部进度：删掉 `%APPDATA%\LostCompound\` 下的 `profile.json` 与 `save.json`。
