# LostCompound

一个终端(TUI)回合制 Roguelike 的 **Java → C# 移植 / 重写**练习项目。

原本是一份 Java 版的小游戏，现在一边移植一边按设计文档重做，顺便学 C#。

---

## 跑起来

**需要 .NET 10 SDK。**

```powershell
# 开发时（在 Rider / Visual Studio 里直接 F5 也行）
dotnet run --project LostCompound\LostCompound

# 或者发布一个单文件 exe
dotnet publish LostCompound\LostCompound -c Release -r win-x64 `
  --self-contained true -p:PublishSingleFile=true -o publish
```

**⚠️ Windows 上用传统控制台（conhost）跑，界面会满屏 `[41;1H` 这种乱码** ——
因为本游戏的界面全靠 ANSI 转义序列定位，而 conhost 默认不解析它们。

程序启动时会自己调用 `SetConsoleMode` 打开虚拟终端处理，所以**正常情况下双击 exe 就能玩**。
如果还是乱码，用 **Windows Terminal** 打开，或者改一下系统的「默认终端应用程序」。

## 怎么玩

**主菜单**

```
  1. 开始游戏     选一个环境，生成一层地图
  2. 退出游戏
```

**地图**：10×10 的迷宫，`*` 是你，`?` 是没探过的房间。
输入方向移动：`0` 上、`1` 下、`2` 左、`3` 右、`4` 退出。

**战斗**（走进战斗房或 Boss 房自动开始）

```
  1. 攻击
  2. 防御        本回合加 5 点护盾
  3. 使用背包道具
  4. 徒手合成
  5. 饰品栏
```

**界面**

```
┌─ 敌 人 ──────────┐  ┌─ 地 图 ───────────────┐
│ [0] 僵尸(30.0)   │  │ +---+---+             │
│ [1] 岩浆怪(80.0) │  │ | * |   |             │
│ [2] （空）       │  │ +   +---+             │
└──────────────────┘  │ | F   ?               │
┌─ 日 志 ──────────┐  │ +---+---+             │
│ 战斗日志滚动显示   │  │                       │
└──────────────────┘  └───────────────────────┘
┌─ 输 入 ──────────┐  ┌─ 状 态 ───────────────┐
│ > _              │  │ 当前房间:Start        │
└──────────────────┘  │ 血量:200.0 防御:5.0   │
                      └───────────────────────┘
                      ┌─ Buff ────────────────┐
                      │ 流血: 每回合7伤 剩余2 │
                      └───────────────────────┘
```

## 调试指令

**在主菜单输入 `255`** 进入 debug 模式，之后：

| 输入 | 作用 |
|---|---|
`127` | 超雄模式（挂一个超雄综合症 buff，STR 暴涨） |
`128` | 解锁全部配方 |
`129` | 按 ID 定量发放任意道具 |
`130` | 按 ID 加任意 buff |

**没开 debug 时这些编号等同于乱输**，什么都不会发生。

**主菜单**在 debug 模式下会多出两项：

```
  3. 调试战斗     选怪物 + 选地形，直接开打
  4. 获取道具     给调试玩家发道具
```

## 目前做到哪了

**能玩**：单层地图探索 → 战斗 → 合成 → 打 Boss。

**已实现**

- 地图：迷宫生成、迷雾、6 种房间（起始 / 战斗 / Boss / 空房 / 合成台 / 空白）
- 战斗：回合制、攻击 / 防御 / 用道具 / 徒手合成、护盾值制、DEF 减伤
- 道具：27 个道具类；配方 0（10 条）+ 配方 1（9 条）
- 状态效果：Buff 体系（有 ID 表与工厂，支持永久 buff）
- 环境：熔岩瀑布（水量 / 缺水削 STR）、水淹洞穴（水位 / 判负 / 热硫堵口）
- 怪物：僵尸、岩浆怪、龙、作孽双子、测试假人
- 终端界面：左右分栏、独立的敌人 / 日志 / 输入 / 状态 / Buff 框

**还没做**

- 地图只做了 2 种（设计文档里有 7 种），而且**只有 1 层**（设计是 10~12 层）
- 配方 2 / 配方 3、附魔系统
- 通关进度解锁、fatal 模式、Hyberty Boss 战
- 背包 / 饰品栏的容量成长
- 相当一部分道具与怪物

**具体缺口以 `DESIGN.md` 第十二章「实现状态」为准** —— 那一节就是专门用来避免
「以为做了其实没做」的。
