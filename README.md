# LostCompound

一个 Java 写的 Rogue-like 游戏。

> 作为新手练习项目，用来学习 Java、游戏逻辑和地图生成。

## 项目简介

LostCompound 是一个基于 Java 控制台的 Rogue-like 游戏。

玩家需要在随机生成的地图中探索，收集化合物，合成道具，与怪物战斗。

## 当前功能

- 道具系统
- 背包堆叠与消耗
- 合成系统
- 随机地图生成
- 基础战斗
- 多个环境房间

## 运行环境

- JDK 17 或更高版本
- IntelliJ IDEA（推荐）

## 如何运行

1. 克隆或下载本项目
2. 用 IntelliJ IDEA 打开项目
3. 等待 Gradle 或依赖加载完成
4. 运行主类 demo
5. 若要体验boss 运行demo02
